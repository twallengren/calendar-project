# Coverage assessment snapshot

Generated by `tools coverage` from the blessed data 12.0.0. Counts include every covered civil date and use the same effective
confidence as the query API (`assessment(date)`), so this table is a faithful
summary of what the published data will and will not answer.

Two questions are counted separately, because they depend on different evidence
scopes (see `spec/SPEC.md`, *Questions and the scopes they need*):

- **Business day** — `is_business_day`, navigation, counts and financial date
  operations. Needs scheduled closures and unscheduled exceptions. UNKNOWN dates
  raise `UnresolvedDateException` / `UnresolvedDateError` from these operations.
- **Session** — `close_time`, `is_early_close` and `status`. Additionally needs
  early-close evidence, so a calendar with an early-close gap can be fully
  answerable for business days while its close times stay UNKNOWN.

PROJECTED dates remain usable with their stated uncertainty. Sources and scope
intervals are linked in each calendar's compiled metadata; the canonical evidence
registers are under `sources/`.
